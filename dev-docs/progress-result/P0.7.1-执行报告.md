## 5. 技术方案

### 5.1 explore 只读 Reviewer

```javascript
const reviewText = await agent(reviewPrompt, {
  label: 'Audit-Reviewer',
  agentType: 'explore',  // 只读，无 write 工具
  timeoutMs: 3600000
})
```

explore agent 只有读文件/grep/搜索能力，无法修改任何文件。4 次审计全部 codeUnchanged=true。

### 5.2 extract-review.mjs 从 journal 提取

Reviewer 的文本输出存储在工作流 journal 中。`extract-review.mjs` 脚本：
1. 自动查找最新 journal 文件
2. 提取 agent result 字段
3. 处理非纯 JSON 输出（从文本中提取 JSON 对象）
4. 修复 LLM 常见畸形（key 后缺值：`"reason","fileRef"` → `"reason":"","fileRef"`）
5. 写入格式化 review.json

### 5.3 源码修改→审计 invalid

```javascript
if (!codeUnchanged) {
  return { status: 'invalid', converged: false, codeUnchanged: false }
}
// 只有 codeUnchanged=true 才继续收敛判定
```

### 5.4 contradicts 分类指导

prompt 中增加明确示例：
- 值不匹配（阈值 5→10）= contradicts
- 功能部分缺失 = partial
- 功能完全不存在 = missing
